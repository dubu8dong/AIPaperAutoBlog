# LLM의 최단경로 일반화

**부제:** Generalization in LLM Problem Solving: The Case of the Shortest Path

## 한 줄 결론
언어모델은 본 적 없는 공간 구조에 대한 전이는 잘 해결하지만, 문제 길이가 길어질수록 재귀적 불안정성으로 일관된 실패를 보인다.

## TL;DR (요약)
- 합성적 최단경로 문제를 통제된 환경에서 구성해 일반화 성능을 평가  
- 공간적 전이(spatial transfer)는 높은 성공률을 보였으나 길이 확장(length scaling)에서 크게 성능 저하  
- 모델별 학습 파이프라인 단계(데이터 커버리지, 강화학습, 추론 스케일링)가 성능에 미치는 영향 분석  
- 강화학습은 학습 안정성에는 기여하나 길이 확장 실패를 극복하지 못함  

## 문제 정의(Problem)
최근 대형 언어모델(Large Language Model, LLM)의 체계적 일반화(systematic generalization) 능력 여부에 대한 논의가 활발하다. 그러나 실제 평가에서는 학습 데이터 분포, 학습 패러다임, 추론 시 기법 등 다양한 요인이 복합적으로 작용하여 실패의 원인을 명확히 구분하기 어렵다.  
이를 해결하기 위해 본 연구는 최단경로(Shortest Path) 계획 문제를 선택했다. 최단경로 계획은 그래프 기반의 순차적 최적화 문제로, 합성(synthetic) 환경에서 두 가지 독립적인 일반화 축인 공간 전이(spatial transfer)와 길이 확장(length scaling)을 분리해 평가할 수 있다.

## 제안 방법(Method)
1. 합성 환경 구축  
   - 무작위로 생성된 그래프 지도(map)를 기반으로 노드 간 최단경로 문제 설정  
   - 학습용 지도와 테스트용 지도를 분리하여 공간 전이를 엄격히 평가  
2. 일반화 축 정의  
   - 공간 전이(Spatial Transfer): 학습에서 본 적 없는 새로운 지도 구조에서의 성능  
   - 길이 확장(Length Scaling): 훈련 시 경로 길이보다 긴, 더 긴-호라이즌 문제에 대한 성능  
3. 학습 파이프라인 단계별 분석  
   - 데이터 커버리지(Data Coverage): 그래프 크기와 난이도 분포를 조절하며 모델의 기본 능력 한계 확인  
   - 강화학습(Reinforcement Learning, RL) 추가 학습: 정책 안정성(stability) 향상 여부 확인  
   - 추론 단계 스케일링(Inference-time Scaling): 더 긴 맥락을 처리하기 위한 기법 적용 후 성능 변화 관찰  

이러한 설계를 통해 각각의 요인이 공간 전이와 길이 확장에 미치는 영향을 독립적으로 분석했다.

## 핵심 기여/차별점(Contributions)
- 합성된 최단경로 계획 문제를 통한 일반화 평가 프레임워크를 제안  
- 공간 전이와 길이 확장의 두 가지 일반화 축을 명확히 분리하여 실험  
- 데이터 커버리지, 강화학습, 추론 스케일링 단계별 성능 기여도를 정량적으로 분석  

## 한계/리스크(Limitations)
- 모델의 길이 확장 실패 원인으로 재귀적 불안정성(recursive instability)을 지적했으나, 구체적 메커니즘은 초록 기준으로는 확인 불가  
- 합성 환경에서 얻은 결과가 실제 자연어 문제나 복합 최적화 태스크로 전이될 수 있는지는 불명확  
- 구현된 강화학습 및 추론 스케일링 기법은 제한된 범위에서만 검증되었으며, 다양한 LLM 아키텍처에 대한 일반화는 확인되지 않음  

## 실무 적용 아이디어(Practical Takeaways)
- LLM을 이용한 경로 계획 및 최적화 태스크에서 문제 길이가 길어질수록 모델의 불안정성 여부를 사전 검증  
- 학습 데이터 커버리지를 조절해 다양한 구조적 변형에 대한 전이 성능을 평가하고 보완  
- 추론 단계에서 길이별 스케일링 기법을 적용해 일정 부분 성능 향상을 도모하되, 근본적인 길이 확장 실패를 해결하려면 추가 연구 필요
