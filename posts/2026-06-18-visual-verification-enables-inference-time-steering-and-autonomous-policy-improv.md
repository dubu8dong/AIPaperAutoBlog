# 비전 검증으로 로봇 정책 개선
**부제:** Visual Verification Enables Inference-time Steering and Autonomous Policy Improvement

## 한 줄 결론
추론 시 비전 검증을 통해 로봇 정책 성능을 추가 데이터 없이 향상시키고, 검증된 자체 롤아웃으로 오프라인 자율 개선을 달성함.

## TL;DR (요약)
- 제너레이터-검증기(generator-verifier) 프레임워크인 VERITAS를 제안한다.  
- 그래디언트-프리(gradient-free) 시각적 검증기를 이용해 추론 시 행동을 평가 및 조정함으로써 추가 훈련 없이 성능을 향상시킨다.  
- 검증된 자체 생성 롤아웃(self-generated rollouts)을 오프라인 학습 데이터로 활용하여 전문가 시연에 버금가는 자율 정책 개선을 달성한다.

## 문제 정의(Problem)
- 현실에 배치된 범용 로봇 정책(generalist policy)은 새로운 환경·작업에서 즉시 최적 행동을 보장하지 못한다.  
- 추가 시연 데이터 수집이나 인간 개입 없이 배포 상태에서 지속적으로 학습하고 성능을 개선할 방법이 필요하다.  
- 추론 시(policy inference time)에 행동을 검증하고 수정하며, 학습 피드백을 확보할 메커니즘이 요구된다.

## 제안 방법(Method)
- 사전 학습된 범용 로봇 정책을 제너레이터(generator)로 활용한다.  
- 그래디언트-프리 시각적 검증기(visual verifier)를 도입해 각 행동의 성공 가능성을 추론 시에 평가한다.  
- 검증 점수에 따라 행동을 선별하거나 정책을 steer함으로써 추가 학습 없이도 즉시 성능 향상을 도모한다.  
- 검증된 자체 생성 롤아웃(self-generated rollouts)을 오프라인 지도 학습 데이터로 활용하여 정책을 파인튜닝한다.

## 핵심 기여/차별점(Contributions)
- 추론 시점에 시각적 검증기를 이용해 행동을 평가·조정하는 제너레이터-검증기(generator-verifier) 프레임워크 VERITAS 제안  
- 추가 데이터 없이 추론 시 정책 성능을 향상시키는 inference-time steering 기법 입증  
- 검증된 자체 롤아웃 기반의 오프라인 학습으로 전문가 시연에 버금가는 자율 정책 개선 결과 달성  

## 한계/리스크(Limitations)
- 실제 물리 로봇 하드웨어 환경에서의 성능 및 안정성은 초록 기준으로는 확인 불가  
- 검증기의 계산 비용 및 추론 지연(latency)에 대한 상세 정보는 제공되지 않음  
- 다양한 작업·시나리오에서 검증된 롤아웃의 일반화 성능은 초록만으로 평가 불가  

## 실무 적용 아이디어(Practical Takeaways)
- 배포된 로봇 정책에 시각적 검증 모듈을 결합하여 현장에서 즉시 성능 향상을 시도할 수 있다.  
- 자체 시뮬레이션 또는 과거 롤아웃 데이터를 검증기로 선별해 오프라인 파인튜닝 데이터로 활용한다.  
- 전문가 시연 없이도 자율 정책 개선 흐름을 구축함으로써 운영 비용을 절감할 수 있다.
