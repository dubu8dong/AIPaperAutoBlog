# G2Rec로 풍부한 유저 관심 표현

**부제:** Structuring and Tokenizing Distributed User Interest Context for Generative Recommendation

## 한 줄 결론
G2Rec는 대규모 산업 환경에서 그래프 기반 사용자 공동소비 행동과 의미론적 토큰화를 통합해 풍부하고 정확한 사용자 관심 컨텍스트를 효과적으로 모델링한다.

## TL;DR (요약)
- 생성형 추천(Generative Recommendation)은 사용자의 과거 행동으로부터 다음 상호작용을 생성적으로 예측하는 최신 패러다임.
- 기존 그래프 기반 방식은 확장성이 떨어지거나 국소 정보만 활용하며, 의미론적 토큰화는 감독 신호 부재로 표현이 부정확.
- G2Rec는 사용자–아이템 공동소비(co-engagement) 그래프와 의미론적 토큰화를 하나의 학습 파이프라인으로 통합.
- 명시적 사용자 관심 레이블 없이도 전반적 관심 프로토타입을 학습하며, 산업 규모 시퀀스 추천에서 성능 우수성 입증.

## 문제 정의(Problem)
생성형 추천은 사용자의 과거 행동 로그를 기반으로 다음 상호작용을 생성하는 방식을 채택하며, 이를 위해 아이템을 토큰(token) 형태로 변환해 모델 입력으로 사용한다.  
그러나:
- 그래프 직렬화(serialization)나 그래프 신경망(Graph Neural Network, GNN) 기반 통합 기법은  
  - 전체 그래프를 확장하여 처리하기 어려워 대규모 환경에서 확장성 문제 발생  
  - 로컬 관계만 포착해 사용자 관심의 전반적 맥락을 놓칠 수 있음  
- 의미론적 토큰화는 휴리스틱에 의존하거나 명시적 학습 목표가 없어  
  - 아이템 간 유사도나 사용자 의도를 정확히 반영하지 못함  
이로 인해 복합적인 사용자 행동과 아이템 의미 컨텍스트를 동시에 효과적으로 주입하기 어려운 실정이다.

## 제안 방법(Method)
G2Rec는 위 문제를 해소하기 위해 다음 요소를 통합한 확장 가능한 프레임워크를 제안한다.
1. **사용자 코-인게이지먼트 그래프 모델링**  
   - 사용자들이 함께 소비(consumption)한 아이템 관계를 노드와 엣지로 구성한 전체 그래프를 생성  
   - 분산 저장 및 처리 구조를 통해 대규모 그래프의 확장성 확보  
2. **의미론적 토큰화**  
   - 아이템 메타데이터(설명, 카테고리 등) 및 행동 패턴을 토큰으로 변환  
   - 명시적 감독 신호 없이도 토큰 간 의미 유사도를 보존하는 표현 학습  
3. **통합 학습 파이프라인**  
   - 그래프 기반 임베딩과 의미론적 토큰을 결합해 생성형 추천 모델에 입력  
   - 사용자 관심 프로토타입(user interest prototype)을 잠재 공간(latent space)에서 무감독으로 학습  
4. **산업 적용 및 온라인 배포**  
   - 실시간 추천을 위한 저지연(low-latency) 추론 인프라와 연동  
   - 공개 데이터셋 뿐만 아니라 실제 서비스 제품면(product surface)에서 A/B 테스트를 통해 검증

## 핵심 기여/차별점(Contributions)
- 통합 프레임워크 제안  
  - 그래프 기반 사용자 공동소비 및 의미론적 토큰화를 하나의 모델로 결합  
- 무감독 프로토타입 학습  
  - 명시적 사용자 관심 레이블 없이도 풍부한 관심 표현 획득  
- 산업 규모 활용성  
  - 분산형 그래프 처리 및 의미론적 토큰화로 대규모 시퀀스 추천 시스템에 적용 가능  
  - 온라인 배포 및 공개 데이터셋 실험에서 기존 방법 대비 성능 우위 입증

## 한계/리스크(Limitations)
- 초록 기준으로는 구체적인 한계 및 리스크(예: 개인정보 보호, 모델 과적합, 하이퍼파라미터 민감도)가 명시되어 있지 않음.

## 실무 적용 아이디어(Practical Takeaways)
- 클라우드 기반 분산 그래프 DB를 활용해 사용자–아이템 상호작용 그래프를 효율적으로 관리하고 G2Rec의 확장성을 극대화.
- 의미론적 토큰화를 위해 아이템 메타데이터(텍스트, 카테고리 등)를 전처리 파이프라인에 통합해 표현력을 높임.
- 명시적 사용자 태그나 라벨이 부족한 서비스 초기 단계에서 G2Rec의 무감독 프로토타입 학습을 통해 추천 품질을 빠르게 확보.
