# 학생 코드 기반 예제 생성  
**부제:** Personalized Worked Example Generation from Student Code Submissions using Pattern-based Knowledge Components  

## 한 줄 결론  
학생 코드에서 추출한 패턴 기반 지식 컴포넌트를 활용해 생성된 예제는 학습자의 논리적 오류에 더 집중적이고 적합하다.  

## TL;DR (요약)  
- 기존 예제 라이브러리는 고정된 콘텐츠와 추가 저작 부담으로 학습자 오류를 충분히 반영하지 못한다.  
- 제안 방법은 학생 제출 코드를 AST(추상 문법 트리) 분석으로 패턴별 지식 컴포넌트(KC)를 추출하고, 이를 조건으로 생성 모델에 입력해 맞춤형 예제를 만든다.  
- 전문가 평가에서 KC 조건 예제는 주제 집중도와 오류 관련성을 높여 개인화 학습 지원 가능성을 보여준다.  
- 초록 기준으로는 사용된 모델 아키텍처나 정량적 성능 지표는 확인 불가하다.  

## 문제 정의(Problem)  
프로그래밍 연습 플랫폼에서는 미리 정의된 예제와 문제 라이브러리를 활용하나,  
1) 예제 저작에 많은 시간과 노력이 요구되고  
2) 학생 개개인이 작성한 코드의 부분적 오류나 해결 방식과 항상 일치하지 않아 학습 효과가 제한된다.  
학습자가 직면한 논리적 오류를 직접 타깃하는 예제가 부족하며, 강사는 라이브러리 확장을 위해 추가 작업을 해야 한다.  

## 제안 방법(Method)  
1. 입력: 문제 설명과 다수의 학생 코드 제출물  
2. AST(추상 문법 트리) 기반 분석으로 학생 코드 전반에 반복적으로 나타나는 구조적 패턴을 지식 컴포넌트(KC)로 추출  
3. 추출된 패턴별 KC를 조건(condition)으로 삼아 대규모 생성 모델에 입력  
4. 모델이 학습자의 오류 유형과 직결된 맞춤형 워크드 예제(worked example)를 생성  
5. 생성된 예제와 비조건(baseline) 예제를 전문가가 비교·평가  

## 핵심 기여/차별점(Contributions)  
- 패턴 기반 지식 컴포넌트(KC)의 자동 추출: AST 분석을 통해 학생 코드의 반복적 구조 패턴을 KC로 식별  
- KC 조건 생성 파이프라인: 추출된 KC를 활용해 생성 모델을 제어함으로써 학습자의 오류 맥락에 맞춘 예제 제작  
- 전문가 평가를 통한 효과 검증: KC-conditioned 예제가 주제 집중도와 오류 관련성 측면에서 우수함을 입증  

## 한계/리스크(Limitations)  
- 초록 기준으로는 사용된 생성 모델의 구체적 구조나 학습 데이터 규모, 성능 지표가 제시되지 않음  
- 제안 방법의 도메인 범위(프로그래밍 언어, 과제 유형)와 일반화 가능성은 확인 불가  
- 학생 코드 다양성 부족 시 KC 추출의 신뢰성 및 생성 예제 품질 저하 우려  

## 실무 적용 아이디어(Practical Takeaways)  
- LMS(학습 관리 시스템)나 코딩 교육 플랫폼에 KC 추출 모듈을 통합해 실시간 피드백 예제 제공  
- 자동으로 생성된 예제를 과제 제출 후 힌트나 추가 학습 자료로 활용해 개인별 지원 강화  
- 지속적 학생 제출 데이터를 분석해 KC 목록을 갱신·확장함으로써 예제 품질을 유지
