# 순환적 다중 에이전트 시스템
**부제:** Recursive Multi-Agent Systems

## 한 줄 결론
RecursiveMAS는 에이전트 협업을 잠재 공간에서 재귀적으로 처리해 정확도와 효율성을 동시에 향상시킨다.

## TL;DR (요약)
- 기존 다중 에이전트 시스템(MAS)은 주로 텍스트 기반 통신을 통해 협업하지만, 확장에 한계가 존재한다.  
- RecursiveMAS는 잠재 공간 기반의 재귀 계산 구조를 도입해 에이전트 간 상태 전이를 경량화하고 반복적으로 추론을 심화한다.  
- 내부-외부 루프 학습 알고리즘을 통해 전체 시스템을 공동 최적화하며, 안정적인 그래디언트 흐름을 유지한다.  
- 수학·과학·의학·검색·코드 생성 등 9개 벤치마크에서 단일/다중 에이전트 및 재귀 연산 기법 대비 평균 8.3% 정확도 향상과 최대 2.4배 추론 속도 개선을 보였다.

## 문제 정의(Problem)
- 다중 에이전트 시스템(Multi-Agent Systems)은 여러 에이전트 간의 협업을 통해 복잡한 작업을 처리하지만, 메시지 교환 기반의 협업은 통신 지연과 불필요한 토큰 사용을 초래한다.  
- 최근 단일 모델의 재귀적 연산(recursive computation)이 심화된 추론을 가능케 했으나, 에이전트 협업 자체를 재귀적으로 확장하는 연구는 부족하다.  
- 에이전트 간 효율적인 잠재 상태 교환과 반복적 협업을 통해 확장성과 성능을 동시에 달성할 방법이 요구된다.

## 제안 방법(Method)
- RecursiveMAS: 전체 다중 에이전트 시스템을 잠재(latent) 공간 기반의 재귀 계산으로 통합한 프레임워크.  
- RecursiveLink 모듈: 이종 에이전트 사이에 경량화된 인터페이스를 제공해 잠재 사고(latent thought)를 생성하고 에이전트 간 상태를 전이한다.  
- 내부-외부(inner-outer) 루프 학습 알고리즘: 재귀 반복 단계마다 공유 그래디언트 기반 크레딧 할당(credit assignment)을 수행해 시스템 전체를 공동 최적화하며, 그래디언트 소실(gradient vanishing) 없이 안정적인 학습을 보장한다.  
- 이론적 분석을 통해 기존 텍스트 기반 다중 에이전트 시스템 대비 런타임 복잡도를 낮추고, 재귀 학습 시 그래디언트 안정성을 유지함을 증명했다.

## 핵심 기여/차별점(Contributions)
- 잠재 공간 재귀 계산: 에이전트 협업을 잠재 상태 전이에 기반해 반복적으로 심화 추론하는 구조를 제안  
- RecursiveLink 모듈: 경량화된 인터페이스로 에이전트 간 잠재 사고 생성 및 상태 전이를 구현  
- 내부-외부 루프 학습: 공유 그래디언트로 전 단계와 재귀 단계 간 크레딧 할당을 수행해 전체 시스템 공동 최적화

## 한계/리스크(Limitations)
- 평가 범위가 4가지 에이전트 협업 패턴 및 9개 벤치마크에 한정되어 있어, 더 다양한 협업 환경에서의 일반화 성능은 확인 불가  
- 실제 대규모 또는 실시간 시스템에서의 적용 안정성 및 보안/충돌 리스크는 초록 기준으로는 확인 불가  
- 에이전트 수 증가에 따른 확장성 한계 및 자원 소비 측면에 대한 상세 분석은 제공되지 않음

## 실무 적용 아이디어(Practical Takeaways)
- 클라우드 기반 분산 에이전트 협업 시스템에 잠재 공간 재귀 구조를 도입해 통신 오버헤드를 줄이고 추론 심도를 높일 수 있다.  
- 에이전트 간 상태 전이에 RecursiveLink 유사 모듈을 활용해 토큰 사용량을 최소화하고 인터페이스를 경량화할 수 있다.  
- 내부-외부 루프 학습 방식을 응용해 대규모 에이전트 집단의 공동 최적화 워크플로우를 설계할 수 있다.
