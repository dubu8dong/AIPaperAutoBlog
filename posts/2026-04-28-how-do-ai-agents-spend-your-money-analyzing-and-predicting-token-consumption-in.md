# AI 에이전트 토큰 비용 분석
**부제:** How Do AI Agents Spend Your Money? Analyzing and Predicting Token Consumption in Agentic Coding Tasks

## 한 줄 결론
에이전트형 코딩 작업은 입력 토큰 중심으로 비용이 매우 높고, 모델 간 효율성 차이가 크며 비용 예측은 부정확하다.

## TL;DR (요약)
- 본 연구는 에이전트 기반 코딩 태스크에서 대형 언어 모델(LLM)의 토큰 소비 패턴을 체계적으로 분석했다.  
- 에이전트형 작업은 일반 코드 추론 및 코드 채팅 대비 최대 1000배 더 많은 토큰을 소비하며, 주로 입력 토큰이 비용을 견인한다.  
- 동일 태스크에서도 실행마다 토큰 사용량이 최대 30배까지 변동하고, 과도한 토큰 사용이 정확도 향상으로 이어지지 않음을 확인했다.  
- 모델별 토큰 효율성 차이가 크며, GPT-5가 Kimi-K2·Claude-Sonnet-4.5 대비 평균 150만 토큰 이상 적게 소비했다.  
- 대부분의 최첨단 모델은 자체 토큰 사용량 예측에 약한 상관도(최대 0.39)를 보여 실제 비용을 체계적으로 과소평가한다.

## 문제 정의(Problem)
- AI 에이전트가 복잡한 인간 워크플로우에 도입되면서 대형 언어 모델(LLM)의 토큰 소비가 급증하고 있다.  
- 특히 에이전트가 코드 생성·수정·검증까지 수행하는 코딩 태스크에서는 다음 세 가지 질문이 제기된다.  
  1. AI 에이전트는 어디에, 얼마나 많은 토큰을 소비하는가?  
  2. 어떤 모델이 토큰 효율성이 높은가?  
  3. 에이전트는 작업 수행 전에 토큰 사용량을 예측할 수 있는가?  

## 제안 방법(Method)
- SWE-bench Verified 데이터셋 기반으로 8종의 최첨단 LLM(예: GPT-5, Kimi-K2, Claude-Sonnet-4.5 등)을 동일한 에이전트 코딩 파이프라인에 적용했다.  
- 각 모델의 실행 궤적(trajectory)을 수집하여 입력 토큰과 출력 토큰으로 분리, 총 토큰 사용량을 측정했다.  
- 실행 전 단계에서 모델이 자체적으로 예측한 토큰 사용량을 기록하고, 실제 사용량과의 상관관계를 평가했다.  
- 태스크별 난이도(전문가 평가)와 실제 토큰 비용 간 상관관계를 분석하여 인간 인지와의 차이를 확인했다.  

## 핵심 기여/차별점(Contributions)
- 에이전트형 코딩 태스크의 토큰 소비 규모 및 패턴을 최초로 정량적 분석: 입력 토큰이 비용 주축이며 일반 코드 작업 대비 1000배 차이.  
- 모델별 토큰 효율성 비교: GPT-5가 평균 150만 토큰 이상 절감, Kimi-K2·Claude-Sonnet-4.5는 높은 과소비 경향.  
- 토큰 사용 예측 능력 평가: 모델 스스로 예측한 비용과 실제 비용 간 최대 상관도 0.39로 낮으며, 체계적 과소추정 경향 관찰.  

## 한계/리스크(Limitations)
- 분석 대상이 SWE-bench Verified 기반 코딩 태스크로 한정되어 있어, 다른 도메인에 일반화하기에는 추가 검증이 필요하다.  
- 비용 예측 평가 방법의 구체적 알고리즘 및 학습 과정은 초록 기준으로 확인 불가하다.  
- 토큰 사용량과 함께 실행 시간, 비용 대비 품질 지표(예: 코드 안정성) 등의 추가 평가가 이루어지지 않았다.  

## 실무 적용 아이디어(Practical Takeaways)
- 입력 토큰 모니터링: 에이전트 실행 전 예상 입력 토큰량을 산정해 비용 예산을 사전 조정한다.  
- 모델 선택 전략: 비용-정확도 곡선을 분석해 중간 비용 구간에서 최적 성능을 내는 모델을 중심으로 배포한다.  
- 비용 예측 도구 도입: 자체 예측 모델을 보완하기 위해 과거 실행 데이터를 기반으로 한 비용 예측 파이프라인을 구축한다.
