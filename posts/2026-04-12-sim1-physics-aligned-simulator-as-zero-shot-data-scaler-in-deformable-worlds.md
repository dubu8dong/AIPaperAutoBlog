# 물리 정합 시뮬로 변형 조작 대규모화

**부제:** SIM1: Physics-Aligned Simulator as Zero-Shot Data Scaler in Deformable Worlds

## 한 줄 결론
SIM1은 실제 시연 기반 물리 정합 시뮬레이션으로 제한된 데모를 대규모 합성 데이터로 확장해 변형 물체 조작 정책의 학습 효율을 크게 향상시킨다.

## TL;DR (요약)
- 변형 가능한 물체 조작은 형상, 접촉, 위상 변화로 인해 데이터 집약적인 과제이다.  
- SIM1은 장면 디지털화, 탄성 모델 기반 동역학 보정, 확산 기반 궤적 생성·필터링을 결합한 파이프라인이다.  
- 1:15의 실·가상 데이터 등가 성능, 제로샷 성공률 90%, 실세계 50% 일반화 이득을 달성했다.  
- 초록 기준으로는 자세한 벤치마크 설정이나 제약은 확인 불가하다.  

## 문제 정의(Problem)
로봇이 천, 고무, 젤리 등 변형 물체를 조작할 때는 형상(shape), 접촉(contact), 위상(topology)이 동적으로 상호작용하여 일반적인 강체(rigid-body) 시뮬레이션으로는 현실적인 동역학을 재현하기 어렵다.  
기존 sim-to-real(시뮬레이션에서 실제로 이전) 파이프라인은 강체 추상화에 의존해 기하학 오차, 불안정한 연성(soft) 시뮬레이션, 비현실적 움직임을 초래하며, 정작 실제 데이터를 대체할 만큼 정확한 합성 데이터를 제공하지 못한다.  

## 제안 방법(Method)
SIM1은 물리 정합(real-world aligned) 데이터를 생성하기 위한 실→시→실 데이터 엔진이다.  
1. 실세계 장면을 계측하여 메트릭(metric)-일치 디지털 트윈을 구성한다.  
2. 탄성(elastic) 모델링을 통해 연성 물체의 변형 동역학을 보정(calibration)한다.  
3. 확산(diffusion)-기반 궤적 생성기를 활용해 초기 관측으로부터 다양한 행동 궤적을 합성하고, 품질 필터링을 거쳐 시뮬 데이터로 확장한다.  
이 과정을 통해 희소한 실제 시연만으로도 시뮬레이션상에서 고품질 합성 감독(supervision)을 대규모로 확보한다.  

## 핵심 기여/차별점(Contributions)
- 실제 계측 기반 메트릭 일치 디지털 트윈과 탄성 동역학 보정을 결합해 물리 정합 시뮬레이션을 구현.  
- 확산 기반 궤적 생성과 품질 필터링 파이프라인으로 희소 시연을 대규모 합성 데이터로 확대.  
- 순수 합성 데이터만으로도 1:15의 실·가상 데이터 동등 성능 달성, 제로샷 90% 성공률 및 실세계를 50% 더 잘 일반화.  

## 한계/리스크(Limitations)
- 초록 기준으로 시뮬레이션 보정 과정의 세부 매개변수 선정 및 일반성 제한 사항은 확인 불가.  
- 복잡한 재질 특성, 조명, 센서 노이즈 등 현실 조건이 반영되는 정도는 초록에서 언급되지 않음.  

## 실무 적용 아이디어(Practical Takeaways)
- 소수의 실제 데모를 기반으로 메트릭 일치 디지털 트윈을 구축해 초기 시뮬레이션 환경을 마련할 수 있다.  
- 연성 동역학 보정을 위해 탄성 모델 매개변수를 식별·최적화하는 과정을 도입해 시뮬레이션의 현실성을 높인다.  
- 확산 기반 궤적 생성 모듈과 품질 필터링을 결합해 부족한 실제 데이터로부터 대규모 합성 감독을 확보하고, 정책 학습 데이터셋을 확장한다.
