# 창의성과 품질을 잡는 LLM 튜닝

**부제:** CreativeInstruct: Scalably Teaching LLMs to Balance Quality, Creativity, and Diversity

## 한 줄 결론
CreativeInstruct는 특수 토큰 스팬을 이용해 대형 언어 모델(LLM)의 창의성, 다양성, 품질을 균형 있게 향상시킨다.

## TL;DR (요약)
- 사후 훈련된 LLM은 품질은 높지만 창의성과 다양성이 감소하는 문제가 있다.  
- CreativeInstruct는 [StartCreativity] 토큰을 주입하는 방식으로 창의적 편향을 제어하는 대규모 명령어 튜닝 방법이다.  
- 내러티브 생성 실험에서 기존 멀티모델·디스틸레이션 기법과 비교해 다양성을 유지 또는 초과하면서 품질 저하 없이 동작한다.  
- 인간 평가에서 70.3%의 사례에서 더 높은 창의성을 기록했으며, 강화학습(RL) 기반 과제에서도 성능 향상을 보였다.

## 문제 정의(Problem)
사후(post-)훈련된 LLM은 기본 모델 대비 생성 품질이 향상되지만, 출력의 다양성과 창의성이 급격히 감소하는 부작용이 있다. 이로 인해 스토리 생성과 같이 명시적으로 창의성을 요구하는 작업은 물론, 강화학습 기반 과제에서도 모델 성능을 제한한다. 기존 해결책으로 멀티모델 앙상블이나 모델 디스틸레이션 기법이 제안되었으나, 추론 시 여전히 여러 모델을 사용해야 하고, 생성 품질과 다양성 간의 균형을 만족시키기 어렵다.

## 제안 방법(Method)
CreativeInstruct는 단일 LLM에서 품질·창의성·다양성을 조절하는 명령어 튜닝(instruction-tuning) 기법이다.  
1. 데이터 준비: 사후 훈련된 LLM의 출력 중 창의적·비창의적 예시를 라벨링해 학습 집합을 구성.  
2. 특수 토큰 삽입: "[StartCreativity]" 스팬(span)을 통해 창의적 문맥을 모델 입력에 주입함으로써 창의적 출력을 유도.  
3. 구조적 다양성 지표: 그래프 편집 거리(graph edit distance)를 기반으로 내러티브 수준의 변주를 계량화해 다양성을 평가.  
4. 훈련 및 평가: 단일 모델만으로 다양한 출력 분포를 확보하면서 품질 저하 없이 창의성·다양성을 증진.

## 핵심 기여/차별점(Contributions)
- [StartCreativity] 스팬을 활용한 대규모 명령어 튜닝으로 창의적·기본 모델 유사 출력을 함께 학습.  
- 그래프 편집 거리 기반의 구조적 다양성(metric) 제안으로 내러티브 변주를 정량적으로 평가.  
- 멀티모델·디스틸레이션 대비 품질 저하 없이 단일 모델만으로 다양성 및 창의성 향상 달성.

## 한계/리스크(Limitations)
- 초록 기준으로는 다른 도메인(예: 기술문서, 코드 생성)에서의 적용 가능성은 확인 불가.  
- 구조적 다양성 지표가 문장 수준의 어휘·의미 다양성을 완전히 포착하는지 불확실.  
- 평가 실험이 주로 내러티브 생성과 일부 강화학습 과제에 국한되어 있어, 일반화 범위에 제약이 있을 수 있음.

## 실무 적용 아이디어(Practical Takeaways)
- 명령어 튜닝 시 특별 토큰을 도입해 생성 스타일(창의성, 형식 등)을 제어해볼 것.  
- 생성 다양성을 평가할 때 그래프 편집 거리와 같은 구조적 메트릭을 추가 도입해보자.  
- 사후 훈련된 LLM을 그대로 사용하는 대신, CreativeInstruct 방식으로 미세 조정해 창의성과 품질 간 균형을 잡을 수 있다.
