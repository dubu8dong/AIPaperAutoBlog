# 비디오 생성으로 추론하는 OpenCoF  
**부제:** OpenCoF: Learning to Reason Through Video Generation  

## 한 줄 결론  
OpenCoF는 시간적 감독 데이터셋과 추론 토큰 설계로 비디오 기반 체인-오브-프레임 추론 성능을 크게 향상시켰다.  

## TL;DR (요약)  
- 체인-오브-프레임(Chain-of-Frame) 추론은 시계열로 연결된 프레임을 통해 논리적 결론을 도출하는 새로운 접근이다.  
- OpenCoF-17K 데이터셋은 11개 과제 패밀리에 걸친 영상 추론 예제를 포함하며, Wan-CoF 모델은 이를 활용해 기존 대비 벤치마크 성능을 개선했다.  
- 시각 추론 토큰과 텍스트 추론 토큰을 도입해 저수준 시각 정보와 고수준 의미 정보를 중간 추론 상태로 조직화했다.  
- 평가 결과, 다양한 시간적 감독과 명시적 추론 메커니즘이 결합되어야 강력한 영상 추론이 가능함을 확인했다.  

## 문제 정의(Problem)  
- 대규모 언어·비전 모델에서 논리적 결과를 신뢰성 있게 도출하려면 중간 추론 과정을 명확히 설계해야 한다.  
- 기존 Chain-of-Thought(CoT) 방식은 텍스트 토큰 연결에 집중되지만, 영상 생성 분야에는 시계열 프레임으로 추론을 전개하는 Chain-of-Frame(CoF) 개념이 있다.  
- 현행 비디오 생성 모델은 일반 비디오 코퍼스 중심으로 학습되어, CoF 추론을 위한 다양하고 체계적인 감독 신호 및 구조화된 설계가 부족하다.  

## 제안 방법(Method)  
- OpenCoF 프레임워크는 크게 세 가지 요소로 구성된다.  
  1. OpenCoF-17K 데이터셋: 11개 과제 패밀리를 포괄하는 영상 추론 예제를 수집·라벨링.  
  2. Wan-CoF 모델: Wan2.2-I2V-A14B 기반 비디오 생성 모델을 OpenCoF-17K로 미세조정하여 시간적 감독 효과를 연구.  
  3. 추론 토큰 메커니즘:  
     - 시각 추론 토큰(visual reasoning token)을 통해 저수준 시각 특징을,  
     - 텍스트 추론 토큰(textual reasoning token)을 통해 고수준 의미 정보를 중간 상태로 도입.  
- 네 개의 비디오 추론 벤치마크에서 Wan-CoF가 기준 성능을 넘어서는 성과를 보였으며, 다양한 깊이(depth), 노이즈 제거 단계(denoising steps), 공간·시간 차원별 토큰 기여도를 분석했다.  

## 핵심 기여/차별점(Contributions)  
- OpenCoF-17K: 11개 과제 패밀리를 아우르는 추론 중심 비디오 데이터셋 공개.  
- Wan-CoF: 시간적 감독을 강화하여 기존 Wan2.2-I2V-A14B 대비 네 개 벤치마크에서 의미 있는 성능 향상 달성.  
- 추론 토큰 설계: 시각·텍스트 토큰을 활용해 중간 추론 상태를 구조화하고, 공간 및 시간적 추론 능력 제고.  

## 한계/리스크(Limitations)  
- OpenCoF-17K 데이터셋의 세부 구성(샘플 수, 비디오 길이 등)은 초록 기준으로는 확인 불가.  
- Wan-CoF의 학습 비용 및 실시간 추론 효율성 정보는 제공되지 않음.  
- 제안된 토큰 메커니즘이 모든 영상 추론 과제에 일반화될지 여부는 초록 기준으로는 확인 불가.  

## 실무 적용 아이디어(Practical Takeaways)  
- 도메인별 영상 추론 과제에 대응하기 위해 독자적 시간적 감독 데이터를 구축하고, 모델을 미세조정할 것.  
- 시각·텍스트 추론 토큰을 기존 비디오 생성 파이프라인에 도입하여 중간 상태 해석 가능성을 높일 것.  
- 주목도(attention) 분석을 통해 추론 과정에서 유의미한 프레임이나 토큰을 식별하고, 성능 개선에 활용할 것.
