# 지오메트리 기반 자가진화 3D 추론
**부제:** SpatialEvo: Self-Evolving Spatial Intelligence via Deterministic Geometric Environments

## 한 줄 결론
지오메트리적 정확성을 기반으로 모델 합의 대신 물리적 검증을 활용해 3D 공간 추론 성능을 지속 개선하는 자기진화 프레임워크를 제안한다.

## TL;DR (요약)
- 3차원(3D) 공간 추론은 기하학 주석 비용으로 인해 모델 성능 개선에 제약이 있다.  
- SpatialEvo는 결정론적 기하 환경(Deterministic Geometric Environment, DGE)을 활용해 무주석 3D 장면을 노이즈 없는 오라클로 전환한다.  
- 질문자(questioner)와 해답자(solver)가 공유 파라미터를 기반으로 번갈아 학습하며, 모델 합의 대신 기하학적 정답을 제공한다.  
- 카테고리별 약점에 집중하는 동적 커리큘럼으로 수동 설계 없이도 학습이 최적화된다.  
- 다양한 벤치마크에서 3B/7B 모델 모두 최고 성능을 기록했다.

## 문제 정의(Problem)
3D 장면에 대한 공간 추론은 로봇 제어, 증강현실, 자율주행 등에서 필수적이다. 그러나 기하학적 주석(annotation) 작업은 비용과 시간이 많이 소요되며, 자체 예측에 기반한 의사 레이블(pseudo-label)을 사용하면 모델이 스스로 만든 오류가 반복 강화되는 한계가 있다.

## 제안 방법(Method)
SpatialEvo는 결정론적 기하 환경(DGE)을 중심으로 다음 요소를 결합한다.
- DGE: 점군(point cloud)과 카메라 포즈 정보로부터 16개 공간 추론 과제를 명시적 검증 규칙(rule)으로 정의해, 무주석 3D 장면을 완전 정확한 대화형 오라클로 변환  
- 공동 정책(shared-parameter policy): 질문자와 해답자가 동일한 모델 파라미터를 공유하면서 교대로 역할을 수행  
- 동적 스케줄러(task-adaptive scheduler): 모델이 약한 카테고리에 자동으로 학습 집중, 수동 커리큘럼 설계 불필요  

## 핵심 기여/차별점(Contributions)
- DGE를 통해 기하학적 정답을 결정론적으로 생성, 모델 합의에 의존하지 않고 오류 축적을 방지  
- 질문자-해답자 역할 전환 방식으로 단일 정책 모델이 양쪽 태스크를 공진화(co-evolve)  
- 태스크 적응형 스케줄링으로 모델 약점을 자동 탐지·보완하는 자기진화 학습 루프 구현  

## 한계/리스크(Limitations)
- 초록 기준으로는 실제 센서 노이즈나 점군 오류 환경에서의 성능 보장은 확인 불가  
- DGE가 전제하는 완전한 점군 및 카메라 포즈 정보는 현실 데이터에서는 확보하기 어려울 수 있음  
- 계산 비용, 메모리 요구량 등 시스템 규모화 관련 상세 정보는 초록에 언급되지 않음  

## 실무 적용 아이디어(Practical Takeaways)
- 3D 시뮬레이션 또는 디지털 트윈 환경에서 DGE 규칙을 먼저 구축해 개발 초기 데이터 부족 문제 해소  
- 질문자-해답자 프레임워크를 로봇 제어 파이프라인에 적용해 자가진단(self-assessment) 모듈로 활용  
- 태스크 적응형 스케줄러를 내부 평가 지표와 연계해 지속적인 성능 모니터링 및 자동 튜닝 프로세스 도입
