# 합성 컴퓨터 장기 생산성 시뮬레이션

**부제:** Synthetic Computers at Scale for Long-Horizon Productivity Simulation

## 한 줄 결론
대규모 합성 컴퓨터 환경과 장기 시뮬레이션은 생산성 에이전트의 학습 효율과 작업 성과를 유의미하게 향상시킨다.

## TL;DR (요약)
- 실제 사용자 환경을 모사한 합성 컴퓨터를 대량 생성하여 폴더 구조와 문서·스프레드시트·프레젠테이션 등 콘텐츠를 포함한 업무 환경을 구축한다.  
- 목표 생성 에이전트(Objective Agent)가 한 달 분량의 전문 산출물을 요구하는 장기 목표를 만들고, 사용자 에이전트(User Agent)가 파일 탐색·협업·문서 작성 등을 수행하며 시뮬레이션을 진행한다.  
- 1,000대 합성 컴퓨터에서 평균 2,000회 이상의 상호작용과 8시간 이상의 에이전트 런타임을 소화하며, 풍부한 학습 신호를 생성한다.  
- 생성된 시뮬레이션 데이터를 통해 에이전트는 도메인 내·외부 생산성 평가 과제에서 성능 개선을 보이며, 수백만 세계로 확장 가능성을 제시한다.

## 문제 정의(Problem)
현실적인 장기 생산성 업무는 각 사용자별 컴퓨터 환경에 깊이 의존하며, 디렉터리 구조와 콘텐츠 집약적 산출물이 주요 컨텍스트를 제공한다.  
기존 연구는 단기 대화형 또는 코드 생성 시나리오에 집중되어 있지만, 전문적 문서 작성, 데이터 분석, 프레젠테이션 제작 등을 아우르는 장기 목표 달성을 위한 시뮬레이션은 데이터 확보와 환경 구축에 어려움을 겪는다.  
실제 사용자 로그를 이용한 학습은 개인정보·보안 이슈가 있고, 수작업 레이블링은 확장성이 낮다.  
따라서 에이전트의 자기 학습(self-improvement)과 강화 학습(Reinforcement Learning)을 위한 현실감 높은 시뮬레이션 환경을 대규모로 제공할 방법이 요구된다.

## 제안 방법(Method)
논문은 “Synthetic Computers at Scale”라는 프레임워크를 제안한다.  
1) 합성 컴퓨터 환경 생성: 폴더 계층 구조를 정의하고 문서·스프레드시트·프레젠테이션 등 다양한 산출물을 콘텐츠로 삽입하여 현실성 있는 사용자 작업 공간을 만든다.  
2) 목표 생성 에이전트(Objective Agent]: 각 컴퓨터의 가상 사용자 속성에 기반해 약 한 달 작업량에 해당하는 다중 전문 산출물 목표를 설계한다.  
3) 사용자 에이전트(User Agent]: 가상의 사용자가 되어 파일 시스템을 탐색하고, 가상 협력자와 조율하며, 문서·분석 보고서·프레젠테이션 등을 순차적으로 생산하여 목표를 완수한다.  
이 과정을 통해 평균 2,000회 이상의 턴(turn)과 8시간 이상의 런타임이 소요되는 장기 시뮬레이션 데이터를 수집한다.

## 핵심 기여/차별점(Contributions)
- 대규모 합성 컴퓨터 환경 생성: 현실감 높은 폴더 구조와 콘텐츠를 자동으로 조합하는 확장성 있는 파이프라인을 제시.  
- 장기 목표 기반 다중 에이전트 시뮬레이션: 목표 생성 에이전트와 사용자 에이전트의 협업으로 전문 산출물 작업 흐름 전반을 시뮬레이션.  
- 개선된 생산성 에이전트 성능 검증: 1,000대 합성 컴퓨터 시뮬레이션 결과, 도메인 내·외부 생산성 평가에서 유의미한 성능 향상을 입증.

## 한계/리스크(Limitations)
- 실험은 1,000대 합성 컴퓨터에 국한되어 있으며, 수백만~수십억 스케일 확장을 위한 인프라 비용과 리소스 요구량은 초록 기준으로 확인 불가.  
- 생성된 환경이 실제 기업 또는 개인 사용자의 복잡한 협업·보안·정책 제약을 충분히 반영하는지에 대한 검증은 추가 연구가 필요.  
- 시뮬레이션의 현실성(reality gap)이 존재할 수 있으며, 실제 사용자 행동 양상과의 정합성 여부는 확인 불가.

## 실무 적용 아이디어(Practical Takeaways)
- 기업 내부 AI 어시스턴트 교육용으로 사용자별 가상 업무 환경을 대량 생성하여 프라이버시 문제 없이 에이전트 성능을 검증하고 튜닝할 수 있다.  
- 장기 과제 기반 강화 학습 시나리오에 합성 컴퓨터 환경을 활용해 에이전트의 계획 수립 능력과 문서 작성·데이터 분석 워크플로우 이해도를 높인다.  
- 도메인 특화 폴더 템플릿과 문서 샘플을 사전 구축하여 고객 맞춤형 시뮬레이션 환경을 자동으로 생성하고, 사용자 채용·교육·평가 시스템에 통합한다.
