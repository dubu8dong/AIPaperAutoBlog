# 수학 문제 대결 벤치마크

**부제:** MathDuels: Evaluating LLMs as Problem Posers and Solvers

## 한 줄 결론
MathDuels는 모델의 문제 출제와 풀이 능력을 동시에 평가해 성능 차이를 극대화하는 자기 검증형 벤치마크다.

## TL;DR (요약)
- 기존 고정 수학 벤치마크는 모델을 풀이자로만 평가해 성능 차별화에 한계가 있었다.  
- MathDuels는 모델을 문제 출제자와 풀이자 역할로 맞대결시키는 self-play(자기 검증) 벤치마크다.  
- 3단계 생성 파이프라인(메타 프롬프트, 문제 생성, 난이도 증폭)과 독립 검증기를 통해 문제를 생성·검증한다.  
- 라쉬 모형(Rasch model)을 이용해 문제 난이도와 모델 능력을 동시 추정하며, 출제 능력과 풀이 능력 간 분리 현상을 밝혀냈다.  

## 문제 정의(Problem)
대형 언어 모델(LLM, large language model)이 기존의 정적 수학 벤치마크에서 거의 만점에 가까운 성과를 내면서, 고정된 문제집 단위 평가만으로는 모델 간 능력 차이를 명확히 구분하기 어렵다는 한계가 대두되었다. 특히 문제 풀이 능력만 따로 평가할 경우, 실제 모델의 출제 역량이나 적응형 난이도 대응력 등 다양한 능력을 반영하기 어려운 상황이다.

## 제안 방법(Method)
MathDuels는 self-play 기반의 이중 역할(dual-role) 벤치마크로, 각 모델이 다음 과정을 통해 서로 경쟁한다.
- 문제 출제 단계  
  1) 메타 프롬프트(meta-prompting)를 통해 출제 가이드라인 설정  
  2) 실제 수학 문제 생성(problem generation)  
  3) 난이도 증폭(difficulty amplification)으로 문제 도전성 강화  
- 문제 검증 단계  
  - 독립 검증기(independent verifier)를 활용해 정의가 모호하거나 잘못된 문항을 제외  
- 성능 평가 단계  
  - 라쉬 모형(Rasch model)을 통해 문제 난이도와 모델별 풀이 능력을 동시 추정  
  - 모델별 출제 능력(author quality)은 해당 모델이 출제한 문제의 평균 난이도로 산정  
  - 풀이 능력(solver ability)과 출제 능력(authoring ability)의 상관 관계 분석  

## 핵심 기여/차별점(Contributions)
- 이중 역할 평가 프레임워크: 모델이 문제 출제자와 풀이자 역할을 모두 수행하는 self-play 벤치마크 제안  
- 3단계 생성 파이프라인과 독립 검증기를 결합해 고품질 문제 자동 생성 및 검증 체인 구축  
- 라쉬 모형 기반 난이도·능력 동시 추정으로 출제 및 풀이 능력의 부분적 분리 현상 발견  

## 한계/리스크(Limitations)
- 초록 기준으로는 MathDuels가 생성하는 문제의 유형 다양성이나 검증기의 정확도 한계 등 세부 품질 평가 결과는 확인 불가  
- 라쉬 모형 적용의 통계적 가정이 모든 문제군에 적합한지, 외부 벤치마크와의 일관성 여부는 초록만으로는 확인 불가  
- 실제 교육용·산업용 시나리오에서의 유효성·안정성 검증 결과는 제시되지 않음  

## 실무 적용 아이디어(Practical Takeaways)
- 내부 모델 성능 평가 시 단일 풀이 평가 대신 문제 출제-풀이 self-play 방식을 도입해 보다 다양한 능력을 측정  
- 난이도 증폭 기법을 활용해 모델 약점을 집요하게 파고드는 적응형 테스트를 구성  
- 라쉬 모형을 적용해 자체 제작한 테스트셋의 문항 난이도와 모델 성능을 동시에 분석·피드백
