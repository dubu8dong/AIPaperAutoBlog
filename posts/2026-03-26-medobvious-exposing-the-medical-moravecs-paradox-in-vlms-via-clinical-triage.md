# 의료 VLM 전처리 검증 벤치마크

**부제:** MedObvious: Exposing the Medical Moravec's Paradox in VLMs via Clinical Triage

## 한 줄 결론
의료 비전-언어 모델에서 입력 유효성 검증은 여전히 해결되지 않은 안전 핵심 과제로 남아 있다.

## TL;DR (요약)
- Vision Language Models(비전-언어 모델, VLM)이 의료 보고서 생성·시각 질의응답에 널리 사용되지만, 사전 입력 무결성 검증을 전제로 동작한다.  
- MedObvious는 총 1,880개 과제로 구성된 벤치마크로, 다중 패널 이미지 세트의 모달리티·방향·해부학적 일관성을 검증하도록 설계되었다.  
- 5단계 난이도 티어와 5가지 평가 인터페이스를 통해 세트 수준의 일관성 검증을 종합적으로 평가한다.  
- 17개 VLM 실험에서 정상 입력에 대한 오탐, 이미지 세트 확장 시 성능 저하, 평가 형식별 정확도 편차가 확인되어 사전진단 검증이 미해결 과제임을 입증했다.  

## 문제 정의(Problem)
의료 영상 해석은 진단 전 단계에서 입력의 유효성을 확인하는 사전 검사(sanity check)가 필수적이다.  
- 올바른 영상 모달리티(예: X선·CT·MRI), 올바른 해부학적 영역, 적절한 촬영 방향·뷰포인트, 무결성 손상 여부를 검증해야 한다.  
- 기존 VLM 벤치마크는 이러한 전처리 검증을 해결된 문제로 간주하여, 입력이 부적합할 때도 그럴듯한 진단 텍스트를 생성하는 위험한 실패 모드를 놓친다.  
- Moravec's Paradox(인간이 쉽다고 여기는 지각 과제가 AI에는 더 어려움)를 의료 영상 VLM에 적용하여, 언어 생성 능력 대비 입력 검증 능력의 역전 현상을 조명한다.  

## 제안 방법(Method)
MedObvious는 의료 VLM의 입력 유효성 검증을 독립적 안전 기능으로 평가하기 위해 설계된 벤치마크다.  
- 총 1,880개 태스크로 구성되며, 다중 화면 이미지(멀티 패널)를 하나의 집합(Set)으로 취급한다.  
- 모델은 각 집합에서 모달리티·방향·해부학적 일관성을 위반하는 패널을 정확히 식별해야 한다.  
- 5개의 난이도 티어(기본 모달리티·방향 불일치부터 임상 트리아지 수준의 복합 검증까지)로 점진적 평가를 지원한다.  
- 오픈엔디드(open-ended), 객관식(multiple-choice) 등 5가지 인터페이스를 제공하여 다양한 운용 환경에서의 견고성을 검증한다.  

## 핵심 기여/차별점(Contributions)
- MedObvious: 의료 VLM의 사전진단 입력 검증에 초점을 맞춘 1,880개 태스크 벤치마크 제안  
- 세트 수준 일관성 검사 및 5단계 난이도·5가지 평가 인터페이스로 안전성 평가 범위 확장  
- 17개 VLM 대조 실험을 통해 정상 입력 오탐, 대규모 세트 확장 시 성능 저하, 평가 형식별 정확도 편차 등 미해결 문제점 분석  

## 한계/리스크(Limitations)
- 벤치마크 구축 과정(데이터 수집·라벨링)과 품질 보증 세부 방법론은 초록 기준으로 확인 불가하다.  
- 평가 대상인 17개 VLM의 구체적 목록과 구성, 최신 모델 포함 여부는 초록에 명시되지 않았다.  
- 실제 의료 시스템 통합 시 규제 준수 및 임상 검증 절차는 논문 초록만으로는 확인 불가하다.  

## 실무 적용 아이디어(Practical Takeaways)
- 의료 AI 파이프라인에 모달리티·해부학적 일관성 검증 모듈을 사전 검사 단계로 별도 구축.  
- 멀티 패널 이미지 일관성 검사 로직을 도입해 입력 나쁜 데이터(garbage in) 유입을 차단.  
- 객관식·오픈엔디드 형식의 테스트 케이스를 활용해 다양한 인터페이스 환경에서 모델 안정성을 주기적으로 점검.
