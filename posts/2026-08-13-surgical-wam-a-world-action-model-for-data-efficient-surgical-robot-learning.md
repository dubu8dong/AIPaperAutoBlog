# 영상 프리트레인 수술 로봇 제어 효율화  
**부제:** Surgical WAM: A World-Action Model for Data-Efficient Surgical Robot Learning

## 한 줄 결론
액션 라벨 없는 내시경 영상으로 사전학습한 세계-동작 모델이 제한된 행동라벨 데이터 환경에서 수술 로봇 제어 성능을 유의미하게 향상시킨다.

## TL;DR (요약)
- 수술 로봇 조작 정책 학습은 행동 라벨이 달린 시연 데이터가 희소하여 데이터 효율성이 낮다는 문제를 겪는다.  
- 본 연구는 라벨 없는 내시경 영상을 활용해 시각적 동역학을 학습한 뒤, 제한된 행동-라벨 데이터로 미세조정하는 Surgical WAM(World-Action Model)을 제안한다.  
- Surgical WAM은 미래 관측과 실행 가능한 행동 청크를 동시에 생성하는 통합 생성 모델이며, 폐쇄 루프 재계획(receding-horizon) 제어를 적용한다.  
- 네 가지 시뮬레이션 수술 과제에서 평균 성공률을 63.5%에서 77.8%로 개선했으며, PegTransfer 과제에서는 20% 포인트 이상의 절대 성능 향상을 보였다.  

## 문제 정의(Problem)
수술용 로봇(예: dVRK) 조작 정책을 학습하려면 동기화된 키네마틱스(kinematics)와 영상 데이터가 필수적이나, 행동 라벨이 달린 시연 데이터는 수집 비용이 매우 높다. 반면 내시경 영상(endoscopic video)은 상대적으로 저렴하고 풍부하지만, 기존 방법들은 이를 주로 시뮬레이션이나 정책 평가용으로만 활용해 폐쇄 루프 제어에 직접 적용되지 않았다.  
중심 질문: 제한된 행동-라벨 시연 예산 하에서 라벨 없는 영상 사전학습이 폐쇄 루프 수술 조작 성능을 개선할 수 있는가?

## 제안 방법(Method)
Surgical WAM은 Cosmos Policy 기반의 통합 생성 모델로, 다음 두 단계를 거친다.  
1. 라벨 없는 내시경 영상으로 시각적 동역학(visual dynamics)을 학습하여 미래 영상 프레임과 행동 청크(action chunks)를 예측하는 세계-동작 모델을 사전학습.  
2. 고정된 행동-라벨 예산(action-labeled budget)으로 모델을 미세조정(fine-tuning)한 뒤, 폐쇄 루프 재계획 방식의 제어기(receding-horizon controller)로 활용.  
배포 시에는 매 타임스텝마다 짧은 행동 청크 prefix를 실행하고, 관측된 결과로 다시 플래닝하여 안정적 제어를 달성한다.

## 핵심 기여/차별점(Contributions)
- 라벨 없는 내시경 영상만으로 수술 장면의 시각적 동역학을 학습하고, 제한된 라벨 데이터로 효과적인 미세조정을 달성.  
- 미래 관측과 실행 가능한 행동 청크를 동시에 생성하는 세계-동작 모델(Surgical WAM)을 제안.  
- 폐쇄 루프 재계획 제어를 통해 시뮬레이션 수술 과제에서 평균 성공률을 14.3%p(63.5%→77.8%) 향상, 접촉-양손 과제에서 최대 20%p 이상 개선.

## 한계/리스크(Limitations)
- 제안된 방법은 시뮬레이션 환경에서만 평가되었으며, 실제 로봇 및 임상 환경에서의 일반화 가능성은 초록 기준으로는 확인 불가.  
- 물리적 제약, 센서 노이즈, 실제 조직과의 상호작용 등 현실적 요소를 다루는지 여부는 초록 기준으로는 확인 불가.  
- 행동 라벨이 필요한 미세조정 단계에서 요구되는 라벨 데이터의 구체적 규모 및 종류는 초록 기준으로는 확인 불가.

## 실무 적용 아이디어(Practical Takeaways)
- 내시경 영상 기반 사전학습 파이프라인을 도입해 행동-라벨 데이터 수집 비용을 절감하고 초기 정책 학습을 가속화할 수 있다.  
- 폐쇄 루프 재계획(receding-horizon) 제어 구조를 적용하면 실시간 반응성과 안정성을 모두 확보하며, 예측 오차 누적을 완화할 수 있다.  
- 실제 수술 시뮬레이터나 가상환경에서 대규모 영상 데이터를 먼저 학습한 뒤, 실제 로봇 데이터로 미세조정하는 단계적 워크플로우를 설계할 수 있다.
