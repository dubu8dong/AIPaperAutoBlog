# 서버 학습으로 연합학습 견고성 강화

**부제:** Enhancing Robustness of Federated Learning via Server Learning

## 한 줄 결론
서버 측 소량 데이터 기반 학습과 클라이언트 업데이트 필터링, 기하중앙값 집계를 결합해 연합학습의 악의적 공격 내성을 크게 향상시킨다.

## TL;DR (요약)
- 연합학습(Federated Learning)은 클라이언트 데이터가 비독립동일분포(Independent and Identically Distributed, IID)가 아닐 때와 다수의 악의적 클라이언트 존재 시 취약하다.  
- 이 논문은 서버 학습(server learning)과 클라이언트 업데이트 필터링, 기하중앙값(geometric median) 집계를 결합한 휴리스틱 알고리즘을 제안한다.  
- 실험 결과, 악의적 클라이언트 비율이 50%를 넘는 극단 상황에서도 모델 정확도가 대폭 개선됨을 보였다.  
- 서버가 보유한 데이터는 소량이거나 합성 데이터여도 분포가 클라이언트 집합 데이터와 일치하지 않아도 효과가 유지된다.

## 문제 정의(Problem)
- 연합학습은 서버에 원본 데이터를 모으지 않고 분산된 클라이언트에서 모델을 학습하지만,  
- 클라이언트들이 독립동일분포(Independent and Identically Distributed, IID)를 따르지 않는(non-IID) 환경에서는 모델 수렴 및 성능이 저하된다.  
- 특히 일부 클라이언트가 악의적으로 업데이트를 조작할 경우 전체 모델의 정확도와 안정성이 크게 훼손된다.  
- 기존의 강인한 집계 방법들은 악의적 클라이언트 비율이 높거나 서버에 충분한 데이터가 없을 때 한계가 있다.

## 제안 방법(Method)
- 서버 학습(server learning): 서버에 소량의 실제 또는 합성 데이터를 보유하고 이를 이용해 초기 모델을 학습·보정.  
- 클라이언트 업데이트 필터링: 클라이언트가 보내온 로컬 업데이트 중 통계적 이상치를 식별해 사전 제거.  
- 기하중앙값(geometric median) 집계: 필터링된 업데이트들을 평균 대신 기하중앙값으로 집계하여 극단치의 영향을 완화.  
- 위 세 요소를 결합한 휴리스틱 알고리즘을 설계·적용하여 견고성을 높임.

## 핵심 기여/차별점(Contributions)
- 서버 측 소량/합성 데이터 기반 학습 기법을 연합학습에 도입하여 초기 모델 품질을 향상.  
- 클라이언트 업데이트 필터링과 기하중앙값 집계를 결합해 악의적 공격에 대한 방어력을 강화.  
- 악의적 클라이언트 비율이 50%를 초과하는 극단적 시나리오에서도 모델 정확도 유지·향상을 실험적으로 입증.

## 한계/리스크(Limitations)
- 제안 방법은 휴리스틱 기반이므로 이론적 수렴성 및 보장에 대한 언급은 초록 기준으로 확인 불가.  
- 서버 데이터의 최소 규모나 품질 요건이 어느 수준 이상이어야 효과를 볼 수 있는지 초록에서 확인 불가.  
- 개별 구성 요소(서버 학습, 필터링, 기하중앙값)가 각기 기여하는 정도에 대한 분석은 초록 기준으로 확인 불가.

## 실무 적용 아이디어(Practical Takeaways)
- 최소한의 대표 데이터(실제 또는 합성)를 서버에 보유해 초기 모델을 사전 학습·보정하는 워크플로우 도입.  
- 클라이언트 업데이트를 중앙 서버로 집계하기 전, 통계적 기준으로 이상치를 필터링하는 모듈 추가.  
- 집계 단계에서 단순 평균 대신 기하중앙값을 사용하도록 연합학습 프레임워크를 확장해 극단값 영향을 감소.
