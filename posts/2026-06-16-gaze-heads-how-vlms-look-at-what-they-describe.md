# VLM 시선 헤드 제어
**부제:** Gaze Heads: How VLMs Look at What They Describe

## 한 줄 결론
VLM의 특정 어텐션 헤드('주시 헤드') 개입을 통해 모델이 설명하는 이미지 영역을 원하는 대로 제어할 수 있다.

## TL;DR (요약)
비전-언어 모델(VLM)의 언어 모델 백본 내 일부 어텐션 헤드(주시 헤드)가 서술 중인 이미지 영역을 추적함을 발견.  
단순 상관 점수 기반 분석을 통해 코믹 스트립에서 이 헤드를 식별하고, 상위 100개 주시 헤드에 어텐션 마스크 개입만으로 83.1% 정확도로 원하는 패널 설명 전환에 성공.  
중간 생성 도중 시선 타깃을 교체해도 현재 패널 기술 후 즉시 새로운 패널로 이동하는 연속 제어 가능.  
코믹 스트립 외에도 COCO 자연 이미지와 2B~32B 파라미터 모델, 다양한 VLM 아키텍처에 걸쳐 동일한 메커니즘을 확인.  
미세조정 없이 메커니즘 분석 기반 개입으로 멀티모달 모델 동작을 실시간으로 제어할 수 있는 실용적 레버 제공.

## 문제 정의(Problem)
비전-언어 모델(VLM)이 이미지 설명 시 내부적으로 어떤 메커니즘으로 특정 영역을 선택하고 서술하는지 불명확하다.  
또한, 모델이 생성하는 설명의 대상 영역을 사용자가 원하는 대로 실시간 제어할 방법이 제시되지 않아 해석 가능성과 사용자 제어성이 제한적이다.

## 제안 방법(Method)
저자들은 코믹 스트립을 공간적 내러티브 테스트베드로 활용하여, VLM 언어 모델 백본의 각 어텐션 헤드가 토큰 단위로 어느 이미지 패널을 주시하는지 상관 점수(correlation score)로 계산해 주시 헤드를 식별했다.  
이후 최상위 100개 주시 헤드에 어텐션 마스크 개입을 시행해 주시 대상 영역만을 활성화함으로써, 모델이 설명 대상을 선택 패널로 정확히 전환하도록 제어했다.  
동일한 어텐션 마스크 개입을 코믹 스트립 중간 생성 단계나 COCO 자연 이미지에도 적용해 연속 제어 및 일반화 가능성을 검증했으며, 파라미터 크기(2B~32B)와 아키텍처 다양성 측면에서도 메커니즘이 반복됨을 확인했다.

## 핵심 기여/차별점(Contributions)
- VLM 언어 모델 백본의 일부 어텐션 헤드(‘주시 헤드’)가 서술 중인 이미지 영역을 자동으로 추적함을 발견  
- 상관 점수 기반 식별과 단일 어텐션 마스크 개입만으로 83.1% 정확도로 모델 서술 대상을 원하는 패널로 전환하는 실시간 제어 레버 제시  
- 코믹 스트립, COCO 자연 이미지, 2B~32B 파라미터 모델, 다양한 VLM 아키텍처 전반에 걸쳐 주시 헤드 메커니즘의 보편성 입증

## 한계/리스크(Limitations)
- 초록 기준으로는 주시 헤드 식별을 위한 상관 점수 산출 방식과 임계값 설정 등 구체적 알고리즘 세부 사항을 확인할 수 없음  
- 일부 frozen-encoder 기반 VLM 계열에서는 유사한 주시 헤드 집합을 발견하지 못함  
- 모든 어텐션 헤드에 개입할 경우 모델의 설명 생성을 완전히 중단함

## 실무 적용 아이디어(Practical Takeaways)
- VLM 기반 이미지 설명 서비스에 주시 헤드 개입 기능을 통합해 특정 객체나 패널 위주로 설명을 맞춤형 제공  
- 사용자 인터랙션을 통해 관심 영역을 지정하면, 실시간으로 모델 응답을 해당 영역으로 전환하는 인터페이스 구현  
- 멀티모달 모델 디버깅 시 주시 헤드 분석을 통해 설명 오류나 비의도적 영역 설명 문제를 진단·개입
