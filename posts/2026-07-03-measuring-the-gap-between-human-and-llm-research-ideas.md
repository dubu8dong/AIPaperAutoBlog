# LLM과 인간 연구 아이디어 차이

**부제:** Measuring the Gap Between Human and LLM Research Ideas

## 한 줄 결론
LLM(대형 언어 모델)의 연구 아이디어 분포는 인간 연구자보다 좁고 특정 패턴에 편중된다.

## TL;DR (요약)
- 대형 언어 모델(LLM)은 연구 아이디어 브레인스토밍에 널리 활용되지만, 기존 평가는 주로 참신성, 실현 가능성, 전문가 선호도에 초점을 맞춘다.  
- 본 논문은 인간 연구자 아이디어와 LLM 아이디어 간 분포적 격차를 정량화하기 위한 대규모 평가 프레임워크를 제안한다.  
- 고품질 인간 논문에서 영감을 준 선행 연구 목록을 역설계하고, 논문 제목 및 요약을 입력으로 LLM에 새로운 아이디어를 생성하도록 유도한다.  
- 제안된 두 축 연구-취향 분류체계(two-axis research-taste taxonomy)로 각 아이디어를 기회 패턴(opportunity pattern)과 연구 패러다임(research paradigm)으로 프로파일링한다.  
- 실험 결과, LLM 아이디어는 브리지 형태의 기회와 종합(synthesis) 방법에 집중된 반면, 인간 연구자의 참조 분포는 보다 넓게 분산됨을 확인했다.

## 문제 정의(Problem)
기존 연구들은 LLM이 생성한 개별 아이디어의 참신성(novelty), 실현 가능성(feasibility), 전문가 선호도(expert preference) 등을 평가해 왔다. 그러나 LLM이 인간 연구자와 비교해 어떤 연구 주제 및 방법론적 분포를 보이는지, 즉 전체 아이디어 스펙트럼에서의 격차는 충분히 탐구되지 않았다. 연구 아이디어의 분포적 차이를 체계적으로 측정할 수 있는 대규모 평가 프레임워크가 부재하며, 이를 통해 LLM의 연구-취향(research taste)이 인간과 어떻게 다른지 파악하는 것이 본 논문의 문제 정의이다.

## 제안 방법(Method)
1. 인간 연구자 아이디어 데이터 구축  
   - 고품질 학술지에 수록된 논문을 선정하고 각 논문의 핵심 아이디어를 뒷받침한 선행 연구 논문 세트를 역설계(reverse-engineering)하여 수집  
2. LLM 브레인스토밍 환경 구성  
   - 논문 제목과 요약(summary)을 입력(prompt)으로 사용하여, 다양한 LLM 모델이 새로운 연구 아이디어를 생성하도록 유도  
3. 연구-취향 분류체계 생성  
   - two-axis research-taste taxonomy를 설계  
     * 기회 패턴(opportunity pattern) 축: 연구 기회의 유형(예: 브리지 형태, 갭 프레이밍 등)  
     * 연구 패러다임(research paradigm) 축: 사용된 방법론(예: 합성(synthesis), 실험 등)  
4. 아이디어 프로파일링 및 정량 분석  
   - 인간 논문 참조 분포와 LLM 생성 아이디어 분포를 taxonomy 기준으로 프로파일링  
   - 두 분포 간의 차이(distributional gap)를 정량적으로 측정하여 분석  

## 핵심 기여/차별점(Contributions)
- 대규모 아이디어 평가 프레임워크 제안: 고품질 인간 연구 논문에서 역설계된 선행 연구 세트를 활용하여 LLM 아이디어 생성 성능을 분포적 관점에서 평가.  
- 연구-취향 분류체계 도입: 기회 패턴과 연구 패러다임 두 축으로 아이디어 성격을 체계적으로 프로파일링할 수 있는 taxonomy를 제시.  
- LLM vs 인간 간 분포적 격차 정량화: 다양한 LLM 모델에 걸쳐 브리지형 기회와 종합적 방법에 편중된 아이디어 분포를 일관되게 관찰함으로써 인간과의 연구 취향 차이를 입증.

## 한계/리스크(Limitations)
- 아이디어 생성은 논문 제목과 요약 정보만 활용하므로, 본문(full-text)의 풍부한 문맥이 반영되지 않을 수 있음.  
- 분류체계는 기회 패턴과 연구 패러다임 두 축에 한정되어 있어, 참신성·실현 가능성 등 다른 평가 관점은 포함하지 않음.  
- 초록 기준으로는 사용된 LLM 모델의 구체적 종류, 학습 환경 및 평가 프로세스 세부 설정을 확인할 수 없음.

## 실무 적용 아이디어(Practical Takeaways)
- LLM 기반 아이디어 브레인스토밍 시 특정 패턴에 편중될 수 있음을 인지하고, 프롬프트 다양화로 생성 균형을 맞출 것.  
- 연구-취향 taxonomy를 도입해 LLM 출력 아이디어를 자동 분류·피드백하는 루프를 구성하면, 아이디어 다양성 확보에 기여할 수 있음.  
- 고품질 인간 연구 논문 역설계를 통해 LLM의 아이디어 영감 원천을 분석하고, 이를 기반으로 실제 연구 워크플로우와 통합하는 검증 프로세스를 마련할 것.
