# LLM 절차 실행 성능 진단
**부제:** When LLMs Stop Following Steps: A Diagnostic Study of Procedural Execution in Language Models

## 한 줄 결론
대형 언어 모델(LLM)은 절차 기반 지침 수행 시 단계가 늘어날수록 정확도가 급감하며, 단계 누락·조기 종료·환각 등 다양한 오류를 보인다.

## TL;DR (요약)
- LLM의 최종 정답 정확도만으로는 주어진 절차를 충실히 실행했는지 평가하기 어려움을 지적한다.  
- 5단계 절차에서는 평균 61%의 최초 답변 정확도를 보였으나, 95단계에서는 20%로 크게 하락한다.  
- 오류 유형으로는 답변 누락, 조기 답변, 자기 수정, 언더트레이스(실행 생략), 불필요 단계 환각이 확인되었다.  
- 절차 길이와 중간 변수 참조 의존도가 늘어날수록 실행 오류가 증가한다.

## 문제 정의(Problem)
많은 대형 언어 모델(LLM, Large Language Model)이 추론 벤치마크에서 높은 성능을 내지만, 단순히 최종 정답 정확도만으로는 사용자가 명시한 단계별 절차를 제대로 따랐는지 알기 어렵다. 본 연구는 단계별 알고리즘을 주고 LLM이 이를 충실히 실행해 최종값을 계산하는 능력을 평가하기 위해, 제어된 진단 벤치마크를 설계한다.

## 제안 방법(Method)
- 단순 산술 연산으로 구성된 단계별 알고리즘과 두 개의 수치 입력을 생성.  
- 알고리즘 길이(5~95단계)와 중간 변수에 대한 참조(look-back 의존도)를 다양화하여 복잡도를 조절.  
- 14개 LLM 모델과 55개 데이터셋을 대상으로 평균 최초 답변 정확도(first-answer accuracy)를 측정.  
- 텍스트 생성 결과를 분석해 실패 유형(누락, 조기 종료, 자기 수정, 언더트레이스, 환각 단계)을 분류.

## 핵심 기여/차별점(Contributions)
- 제어된 절차 실행 진단 벤치마크 제안: 단계별 산술 알고리즘으로 LLM의 절차 수행 능력을 평가.  
- 대규모 실험: 14개 모델, 55개 데이터셋, 단계 수별 성능 변화를 체계적으로 분석.  
- 실행 오류 유형 분류: 누락 단계, 조기 답변, 자기 수정, 언더트레이스, 불필요 단계 환각을 정의하고 빈도 조사.

## 한계/리스크(Limitations)
- 제안된 벤치마크는 단순 산술 연산에 국한되어, 실제 자연어 기반 복잡 절차로의 확장성은 초록 기준으로는 확인 불가.  
- 모델별 하이퍼파라미터 설정이나 아키텍처 차이에 따른 성능 영향은 상세히 다루지 않음.  
- 개선 기법이나 교정 방법론은 제시되지 않아, 실질적인 해결 전략 부재.

## 실무 적용 아이디어(Practical Takeaways)
- 복잡한 절차적 작업에 LLM을 적용할 때는 각 단계별 중간 결과를 검증하는 체계적 체크포인트 도입.  
- 중간 변수 추적 및 재검증 워크플로우를 구축하여 언더트레이스나 환각 오류를 조기에 감지.  
- 사용자 정의 절차 실행 로그를 수집하고, 자가 진단(self-diagnostic) 모듈을 연동해 오류 유형별 대응 방안을 마련.
